O que e o Flask?

O Flask é um microframework para desenvolvimento web escrito em Python. Ele é conhecido como "micro" porque possui um núcleo minimalista, fornecendo apenas as ferramentas essenciais para colocar uma aplicação no ar. Em vez de impor uma estrutura rígida, ele oferece total flexibilidade para que você escolha e adicione apenas as bibliotecas que o seu projeto realmente precisa.

Principais Características

Simplicidade: É possível criar um servidor web funcional com pouquíssimas linhas de código.
Flexibilidade: Você não fica preso a um banco de dados ou formato de formulário específico. É possível integrar extensões conforme necessário.
Base Sólida: Ele utiliza o sistema de templates Jinja2 (para renderizar páginas dinâmicas) e a biblioteca Werkzeug (para gerenciar requisições HTTP).
